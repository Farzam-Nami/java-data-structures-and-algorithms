# Coursework source mapping

This repository presents a reorganized and extended version of the original student exercises. It is not a byte-for-byte reproduction of the earlier submissions.

## Concepts adapted from submitted exercises

| Earlier project folder | Content represented in this repository |
|---|---|
| `sll/`, `Taklif3/sll/`, `Taklif6/Mine/sll/` | Singly linked list, task manager, linked-list selection sort |
| `Taklif4/dll/`, `Taklif6/Mine/dll/` | Doubly linked list and insertion sort |
| `Taklif5/cll/` | Circular linked list and rotation |
| `Taklif9/Vector/demo/` | Dynamic array/vector operations |
| `Taklif10/demo/` | Music playlist, frequency-based and name-based ordering |
| `char/` | Stack and character/delimiter checking |
| `pl/` | Positional list and iterators |

Code was restructured and behavior corrected, including boundary cases, generic typing, sorting and iterator behavior, file input and validation.

## Added after the initial coursework

The following topics were implemented for broader foundational coverage and should not be mistaken for part of the original submission:

- Queue
- Binary search tree, including deletion and traversal
- Binary min/max heap (priority queue)
- Chained hash table
- Undirected graph, breadth-first and depth-first traversal, and shortest unweighted path
- Linear and binary search
- Array-based merge sort and quick sort
- Additional tests and documentation; merge sort of a singly linked list

## Excluded material

- `s1/`: the Scoreboard assignment, excluded from the consolidated collection
- `Taklif6/CodeOstad/`: instructor/reference implementations
- Build artifacts, IDE state, nested backup archives, and duplicated starter projects
